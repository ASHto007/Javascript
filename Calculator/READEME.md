# Calculator 🧮

A simple yet functional **calculator application** built using **vanilla JavaScript**, HTML, and CSS.
This project focuses on implementing **core JavaScript logic**, handling **user input events**, performing **real-time calculations**, and updating the UI dynamically without using any external libraries or frameworks.
The calculator supports basic arithmetic operations and is designed to be clean, responsive, and easy to use.

## ✨ Features
- Addition, subtraction, multiplication, and division
- Real-time display updates
- Clear and delete functionality
- Keyboard and button input handling
- Responsive layout

## 🎯 Concepts Covered
- DOM manipulation
- Event listeners
- Conditional logic
- State management
- Input validation
